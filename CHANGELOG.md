# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2024-11-06

### Added

- Initial release of @lp-labs/ui-components
- Pre-built React components:
  - Button (multiple variants: primary, secondary, danger, ghost)
  - Card (with elevation and padding options)
  - Input (with validation states and help text)
  - Modal (with header, body, and footer sub-components)
  - Badge (with multiple variants and sizes)
  - Alert (with success, warning, danger, info variants)
  - Dropdown (with menu items and dividers)
  - Navbar (with brand, navigation, and toggle components)
- Comprehensive theming system with CSS variables
- Utility-first class names and helper functions
- CSS-in-JS style utilities
- Full TypeScript support with type definitions
- Comprehensive CSS stylesheet with animations and responsive utilities
- Accessible components following WCAG 2.1 AA standards
- Dark mode theme support
- Responsive design utilities
- ESM and CommonJS distribution formats

### Features

- 🎨 Pre-built Components - Ready-to-use React components
- ⚙️ Utility Classes - Flexible utility-first approach
- 🎭 Theming System - CSS variables and theme provider
- ♿ Accessibility - WCAG 2.1 AA compliant
- 📦 Tree-shakeable - Only pay for what you use
- 🔄 Type-safe - Full TypeScript support
- 📱 Responsive - Mobile-first design
- ✨ Dark Mode - Built-in theme switching
